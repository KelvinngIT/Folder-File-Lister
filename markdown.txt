# Folder File Lister → Excel

A simple Streamlit app that lets you select a target folder, list all files, and download the list as an Excel file.

## Features

- Enter any folder path
- Optional recursive scan (include subfolders)
- Option to show/hide hidden files
- Clean table view
- One-click Excel download
